# Day 1 – Agentic AI Workshop

## Sweet Crumbs Home Bakery

### Overview

This assignment explores the fundamentals of Large Language
Models (LLMs), API integration, and prompt engineering using
the Sweet Crumbs Home Bakery use case.

### Technology Stack

- Python
- Google Colab
- Groq API
- GPT-OSS-120B
- OpenAI Python SDK

### Practical Tasks

| Task | Concept | Description |
|------|---------|-------------|
| 1 | Temperature | Compare responses at temperatures 0.2 and 1.2. |
| 2 | Hallucination | Observe model behaviour with and without business facts. |
| 3 | No Memory | Compare independent API calls with conversation history. |
| 4 | Token Comparison | Compare English and Telugu prompt token counts. |
| 5 | Business System Prompt | Design a bakery assistant using five facts, three rules and three customer questions. |

### Customer FAQs

1. What is the price of a chocolate cake?
2. What is the price of a plum cake?
3. Do you make eggless cakes?
4. How early should I place my order?
5. Do you deliver to Kakinada?
6. Can I order a customized birthday cake?
7. Can I get a cake within one hour?
8. What payment methods do you accept?
9. Can I cancel my order?
10. Do you bake fresh cakes for every order?

### Learning Outcomes

- Understanding LLM and API integration.
- Exploring temperature and response variation.
- Understanding hallucination and factual grounding.
- Implementing basic conversation history.
- Comparing multilingual token usage.
- Designing business-specific system prompts.

### Execution

1. Open the Day 1 notebook in Google Colab.
2. Add GROQ_API_KEY to Colab Secrets.
3. Enable notebook access to the secret.
4. Execute all cells and observe the results.

### Conclusion

Day 1 establishes the foundation for developing
intelligent business assistants and understanding
the core concepts required for Agentic AI.
